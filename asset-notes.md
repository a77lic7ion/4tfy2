## Implementation decision

The image-generation quota is currently unavailable. The redesign will use the project-provided images selectively, without repeating an asset across different visual roles, and CSS overlays will protect legibility and crop the watermark away from priority placements where feasible. The revised direction favours decisive readiness and strong professional response over a calm dusk-led look, while preserving the distinction between private security, police, and military.

## New theme asset allocation

The added themes will use distinct focal roles: **Metro Vector** takes the response-bakkie asset, **Watchtower** uses the command-centre asset, and **Civic Guard** uses an image-light interface with the existing estate-access image restricted to a small contextual feature. This keeps the themes visually differentiated even while sharing a finite approved local asset library.
